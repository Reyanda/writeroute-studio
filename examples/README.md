# Worked examples

## `sloppy-report.*`

A deliberately weak professional report. The suggestion file separates safe exact edits from evidence-dependent rewrite frames. The repaired file applies only deterministic edits that clear the complete document gate; vague sourcing and unsupported impact claims remain for author review.

## `evidence-brief.json` and `evidence-completed-report.*`

A bounded policy brief and an accepted draft containing only supplied factual anchors. The validation record reports both the editorial audit and the independent evidence-boundary check.

## `evidence-unsupported-draft.*`

An adversarial draft that invents a budget, implementation date, geographic scale and guarantee. The validation record rejects the unsupported anchors instead of rewriting them into smoother claims.

## `clean-scientific.*`

A clean scientific paragraph with numbers, dates, an estimator, uncertainty and a causal limitation. Repair returns it byte-for-byte.

## `source-legal.*`

A legal sentence audited in source-text mode. The route may identify removable metadiscourse, but the checked output remains byte-for-byte identical because mutation authority was not granted.
